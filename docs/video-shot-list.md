# Demo video shot list

Target final runtime: **2:35–2:45**. Absolute rule: under 3:00, public YouTube, clear audio.

The narration script is ~225 spoken-ish words. At 120–140 wpm that is ~1:36–1:53 of speech, leaving generous space for visible product actions without rushing.

## Recording setup

- Use the canonical Mission Board as the only starting URL.
- Use a completely fresh mission/session.
- Have ONE, Northstar, BoxFox and Evergreen visible as browser tabs once opened by the agent.
- Keep browser zoom and text large enough to read in a 1080p YouTube player.
- Show the real human UI and Agent Activity/Site Tools state; do not use fake terminal overlays.
- No copyrighted music. Voice + product sounds only is safest.
- Do not expose browser/profile/private account information in the capture.

## Before publishing

- Final file < 3:00.
- Audio intelligible on phone speaker.
- Product text readable at 1080p.
- No real personal information in frame.
- No copyrighted music/trademarks beyond the fictional project brands.
- Public/unlisted is not enough if Devpost requires public: set YouTube visibility to **Public**.
- Watch the entire uploaded YouTube version once after processing; do not assume the local export equals the stream.
